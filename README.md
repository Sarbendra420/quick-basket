# Quick Basket — Neighborhood Kirana & Dry Goods Store

A responsive, multi-page web storefront built for a local neighborhood Kirana shop specializing in hand-sorted nuts, organic seeds, daily staples, and traditional festive sweets.

> **Status:** 🚧 Work in Progress — Currently building out the multi-page layout and modular CSS architecture.

---

## 🛠️ Tech Stack
* **HTML5** — Semantic multi-page structure
* **CSS3** — Modular stylesheets (`main.css` + page-specific CSS), CSS Variables, Flexbox & Grid
* **JavaScript (Vanilla)** — Interactive product filtering and UI logic *(upcoming)*
